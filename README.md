# Irene Mae P. Dimasacupan Portfolio

## Run locally
1. Extract/open this project folder.
2. Open `index.html` in a modern browser.

For the most reliable local preview, run a local server from this folder:
- Python: `python -m http.server 8000`
- Then open `http://localhost:8000`

## Add your images
Create/use the `assets` folder and add these image files:
- `photo.jpg`
- `skill1.jpg`
- `skill2.jpg`
- `skill3.jpg`
- `preview.jpg`

The page will still load without them, but those image areas will be blank.

## Before publishing
Replace the placeholder Facebook, Instagram, Gmail, and Formspree values in `js/main.js`.
